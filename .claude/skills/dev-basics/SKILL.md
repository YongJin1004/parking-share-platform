# 개발 기본 워크플로우

## 개발 시작 시
1. 무엇을 만들지 명확히 파악
2. ai-context 파일들 확인 (이미 구현된 패턴 있는지)
3. 관련 엔티티/API 있는지 체크

## 개발 순서
1. **간단한 버전부터** - 완벽하려 하지 말고 동작하는 것부터
2. **테스트 작성** - 가능한 범위에서 (강제 아님)
3. **실행해서 확인** - 실제로 작동하는지
4. **리팩토링** - 코드 정리

## 코드 작성 규칙
- FastAPI Router 사용
- SQLAlchemy 2.0 스타일 (async 아님, sync)
- Pydantic 모델로 요청/응답 검증
- 환경변수는 .env에서 로드
- 클린 아키텍처: Domain - UseCase - Adapter 구조

## 새로운 것 발견 시
개발 중 중요한 패턴, 규칙, 제약사항을 발견하면:

**프롬프트 예시:**
```
"이 [규칙/패턴]은 중요해. 
다음 세션에서도 기억할 수 있도록 
ai-context/[적절한 파일]에 추가해줘"
```

AI가 스스로 적절한 파일을 선택해서 업데이트함

## 파일 업데이트 시점
- **domain-overview.md**: 비즈니스 규칙 발견 시
- **data-model.md**: 엔티티 구조 확정 시
- **api-spec.json**: API 개발 완료 시
- **external-apis.md**: 외부 API 사용법 파악 시
